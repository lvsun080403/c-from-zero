---

## 这不是教程，是一份「对照物」

学 C 最难受的时刻，不是写不出程序，而是：

- 程序跑对了，但你说不出它为什么对；
- 抄了别人的代码，换个输入就错；
- 老师讲过的 `i*i<=k`、`scanf` 返回值，自己写的时候永远想不起来。

这套东西收的是一个大一学期的 13 个真作业：从"输入三个数排序"到"井字棋"。
它们不高级，但**覆盖了 C 语言入门要用的全部骨架**：分支、循环、函数、数组、字符串级遍历、随机数、二维数组与状态判断。

我保留了作业原貌，也保留了当年踩的坑——**README 最后那张"当年 bug 表"就是这个仓库存在的意义**。

## 两个版本，怎么读

| | `plain/` | `commented/` |
|---|---|---|
| 内容 | 纯代码，一行注释都没有 | 文件头有题目/输入/输出/思路，行内有讲解 |
| 行数 | 20–100 行 | 多 30%–60% |
| 适合 | 已经会了，只想抄结构 / 对着敲一遍 | 第一次学，或者忘了某题怎么写 |
| 建议 | 先看 `commented/` 读懂，再对着 `plain/` 默写一遍 | 读的时候顺手改坏一行，看会发生什么 |

两边的**代码逻辑完全一致**，`commented/` 只是多了注释——所以你可以放心地拿 `plain/` 交作业、拿 `commented/` 复习。

## 快速开始

### 1. 只要编译某一个

```bash
gcc plain/01-sort-three.c -o sort-three
./sort-three
```

Windows + MinGW / Dev-C++ / VS 都行；老项目里常见的 **VC6** 也能编译（代码是 C89 风格，变量都在块首声明）。

### 2. 一次把 13 个全编译出来

```bat
build.bat
```

脚本会依次找 `gcc` → `clang` → `tcc`，把 `plain/` 里的 13 个源文件编译到 `build\` 目录，然后告诉你编译了几个、失败几个。

### 3. 没有编译器？用 TinyCC（490 KB，解压即用）

```bat
tcc -o sort-three.exe plain\01-sort-three.c
```

## 当年写错的 8 个地方

这张表是整套代码最有价值的部分——**每一个都是真实运行会出错、而不是"看起来不优雅"的问题**。

| # | 现象 | 原因 | 现在怎么写 |
|---|---|---|---|
| 1 | 阶乘算到 13 变成负数 | `int` 只有 32 位，13! 已经越界 | 进入前就挡掉 `n > 12`，并提示原因 |
| 2 | 判素数慢得离谱 / 结果对但很慢 | 试除一直试到 `k-1` | 只试到 `i * i <= k`，不引入 `sqrt` 避免浮点误差 |
| 3 | 逐位输出最后多一个空格 | 循环里无条件打印分隔符 | 最后一位之后不打印 |
| 4 | 查第 1 个数却说"不存在" | `p` 是 `i + 1`，被写成 `if (p != 1)` | 改成 `if (p != -1)` |
| 5 | 平均值永远是整数 | `sum / cnt` 两个 int 做整数除法 | `(double)sum / cnt` |
| 6 | 数组越界不报错，但结果乱掉 | 先 `count[x]++` 再判断范围 | 先判 `x >= 0 && x <= 9` |
| 7 | 猜中了还打印 Game Over | 判断写在循环里，缺一个"猜中过"的标记 | 用 `win` 标记，循环结束后统一判断 |
| 8 | 井字棋三个空格也算赢 | 只比较相等，没排除空位 | `a == b && b == c && a != EMPTY` |

> 想验证？把 `commented/` 里对应的那一行改回去，重新编译就能看到效果。

## 建议的阅读顺序

不是按 01→13 顺着看，而是按"能力块"分组：

| 阶段 | 题号 | 练什么 |
|---|---|---|
| 先把分支和循环写顺 | 01 02 03 04 | `if` / `for` / `while` 的组合，边界条件 |
| 再练"数字怎么拆" | 05 06 08 | 整除、取模、掩码、递推 |
| 然后是"把状态存下来" | 07 10 11 | 标记变量、数组、桶计数 |
| 最后是"把逻辑拆成函数" | 09 12 13 | 函数拆分、数组传参、二维数组 |

## 常见问题

**编译时报 `'for' loop initial declarations are only allowed in C99 mode`**
把 `for (int i = 0; ...)` 改成先在块首 `int i;` 再 `for (i = 0; ...)`。本仓库的代码本来就是这么写的。

**控制台中文乱码**
源文件是 UTF-8。用 VC6 打开请另存为 ANSI；用 VS / Dev-C++ / gcc 一般没问题。也可以在程序开头加一行 `system("chcp 65001");`（需要 `#include <stdlib.h>`）。

**`scanf` 之后程序像"卡住"了**
其实是在等输入。注意 `scanf("%d", &x)` 里的 `&` 不能少；输入数字后按回车。

**井字棋怎么玩**
输入"行 列"，行列都从 1 开始，例如 `2 3` 表示第 2 行第 3 列。输入非法时不会消耗本回合。
